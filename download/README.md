# دانلود منوبار سایدبار

این پوشه فقط برای دانلود است. هر چهار فایل را از همین‌جا بگیرید و جایگزین `assets/` روی سایت کنید.

| فایل | کار |
| --- | --- |
| `production-sidebar-controls-v1.css` | ظاهر دکمه و فوتر حساب |
| `production-sidebar-controls-v1.js` | ساخت دکمه و اتصال به هندلرهای فعلی |
| `production-sidebar-placement-v2.css` | جای دکمه روی منوبار |
| `production-sidebar-placement-v2.js` | حرکت دکمه دقیقاً همراه منوبار |
| `ghadir-sidebar-download.zip` | هر چهار فایل یکجا |

## دانلود از گیت‌هاب

1. وارد این پوشه شوید: `download/`
2. روی `ghadir-sidebar-download.zip` کلیک کنید
3. دکمه **Download raw file** را بزنید

یا هر فایل را جدا باز کنید و Raw / Download را بزنید.

## نصب روی سایت

```html
<link rel="stylesheet" href="assets/production-sidebar-controls-v1.css" />
<link rel="stylesheet" href="assets/production-sidebar-placement-v2.css" />
<script src="assets/production-sidebar-controls-v1.js"></script>
<script src="assets/production-sidebar-placement-v2.js"></script>
```

اول controls، بعد placement.
